# Grama Kalyana Sports 🏆

**Grama Kalyana Sports** is a dedicated mobile application designed to empower rural communities by providing a professional platform for sports management. 

## 🚀 Features
- **Live Scoring:** Real-time updates for ongoing matches.
- **Role-Based Access:** Secure "Scorer" login to manage match data.
- **Team Management:** Track team performances and player stats.
- **Rural Connectivity:** Optimized for low-connectivity environments.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Backend:** Firebase Firestore & Auth
- **Architecture:** MVVM
